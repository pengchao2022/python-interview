AWS 中 公有实例 和 私有实例的流量流向 过程



私有实例 流量流向：

        私有实例 -> 私有子网路由表 -> NAT 网关 -> 转化地址 -> IGW -> Internet


        要发送到 Internet，必须要有一个Public IP, 因为 私有实例 没有 Public IP , 所以 NAT 网关需要

        绑定一个 EIP 作为 公网 IP 




公有实例 流量流向:

        公有实例 -> 公有子网路由表 -> IGW -> Internet 

        因为公有实例 自身就是有 Public IP 的，所以不需要地址转换 直接通过 IGW 发送到 Internet

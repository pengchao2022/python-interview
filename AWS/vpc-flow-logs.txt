
VPC Flow Logs (VPC 流日志) 

作用：

    - VPC 网络提供类似通话记录

    - 监控 分析 审计进出 VPC 的所有网络流量 


核心作用:

    - 五元组信息: 源IP， 目的IP， 源端口， 目的端口， 协议 TCP/UDP/ICMP

    - 动作:      记录流量是被安全组 security group 或 NACL 接受 accept 还是拒绝 reject 

    - 流量大小:   发送的数据包 数量 和 字节数

    - 时间戳:     流量发生的 开始 和 结束 时间

      注意: flow log 不会记录数据包里的具体内容， 它能看到你访问了网站，但看不到你发送的密码或下载的内容


应用场景:

   - 网络排错:   当应用连接不到数据库 或者 实例之间无法通信时， Flow logs 是救命稻草


   - 安全监控 与 入侵检测: 某台服务器突然向外部未知IP发送了大量数据 


   - 网络合规审计:  Flow logs 可以提供合规审计所需的原始数据

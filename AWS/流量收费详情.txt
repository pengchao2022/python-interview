AWS 流量费用详情


流量类型                             方向                          费用状态

传入到AWS                            入网                          免费 

相同 VPC 相同 AZ                     私有IP通信                     免费

相同 VPC 跨 AZ                       私有IP通信                     收费 按 GB 算

跨 VPC (peering)                    私有IP通信                      收费 按 GB 算


传出到 互联网                         出网                           收费 按 GB 阶梯计费


通过 NAT Gateway                     进出处理                        收费 小时费 + 流量处理费


只要 NAT Gateway 运行， 每小时都要收费 

公网 public IP 按小时收费 收费方式：按小时计费，比例为 $0.005/小时。

ALB 无论你用不用 只要创建了 都会按小时收费， 如果 ALB 全年无休，每月的固定成本大约在 $16 - $17 左右。

NLB 收费 和 ALB 基本一样 每月的固定成本大约在 $16 - $17 左右。

在 AWS 里 安全组 Security Group 和 Network ACL 有什么区别 ？


安全组 security group

                    作用范围:

                           -  实例级别 EC2, RDS, ECS 容器等

                    状态机制:

                           - 有状态    Stateful 

                    规则性质:

                           - 只有 允许规则 白名单 

                    生效方式:

                           - 必须匹配才会放行


Network ACL 

                    作用范围:

                           - 子网级别 subnet 

                    状态机制:

                           - 无状态  stateless

                    规则性质:

                            - 支持 允许 和 拒绝 规则 

                    生效方式:

                            - 按规则编号顺序执行 1-32766



安全组 有状态 它会记住你的连接 ，如果你允许入站 443 端口流量， 它会自动允许对应的出站响应流量 ，你不需要管理出站规则 

NACL  无状态 如果你在 ACL 中允许入站 443 ， 出站规则也必须放行 没放行 流量就会被拦截
